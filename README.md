# 🍔 RestroHub

> A modern food delivery application supporting restaurant discovery, menu browsing, cart management, and order placement with a smooth and intuitive cross-platform UI for Android and iOS.

---

## 📱 Overview

**RestroHub** is a Flutter-based food delivery platform designed to connect hungry customers with their favorite local restaurants. Whether you're craving pizza, momo, or anything in between — RestroHub makes it effortless to discover, order, and track your food in real time.

---

## ✨ Features

### 🧑‍🍳 Restaurant Discovery
- Browse multiple restaurants across different cuisines and locations
- Filter by cuisine type, distance, rating, or delivery time
- View detailed restaurant profiles with menus, photos, and reviews
- Unified multi-vendor experience from a single app

### 🛒 Ordering Experience
- Intuitive menu browsing with categories and item details
- Add items to cart from multiple vendors seamlessly
- Real-time order placement with instant confirmation
- Live order tracking from preparation to doorstep delivery

### 💳 Checkout & Billing
- Secure checkout flow with multiple payment options
- Delivery address management with saved locations
- Itemized billing with tax calculations
- Digital receipt generation after every order

### 📦 Order Management
- Complete order history with reorder functionality
- Real-time order status updates and notifications
- Estimated delivery time tracking
- Easy cancellation and refund workflow

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Framework | Flutter |
| Language | Dart |
| State Management | *(Riverpod)* |
| Backend / API | Supabase / REST API |
| Database | SQLite (Drift) |
| Authentication | Supabase Auth |
| Maps & Location | *(e.g. Google Maps SDK)* |
| Payment | *(e.g. eSewa / Khalti / Stripe)* |
